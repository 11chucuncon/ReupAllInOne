# Colab setup

1. Upload toàn bộ project này lên Google Drive, ví dụ vào thư mục:
   - /content/drive/MyDrive/video-pipeline
2. Mở notebook [colab_render_notebook.ipynb](colab_render_notebook.ipynb)
3. Chạy lần lượt các cell
4. Nếu cần, đổi biến `video_input` thành file video của bạn

Lưu ý:
- Notebook sẽ mount Google Drive và dùng project từ Drive
- Nếu bạn cập nhật backend ở thư mục Drive, Colab sẽ lấy bản mới khi chạy lại notebook
- Nếu bạn muốn chạy trên một thư mục khác, đổi `repo_root` trong cell thứ 2
